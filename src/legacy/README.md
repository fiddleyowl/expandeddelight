# Original 1.21.1 data generators

These Java sources are preserved unchanged from the `1.21-neo` baseline. They use APIs removed before Minecraft 26.1.2 and are excluded from compilation.

The migrated, checked-in JSON in `src/main/resources/` and `src/generated/resources/` is the authoritative data and model source for this port. Edit those resources directly. Do not run the legacy generators over migrated resources.
