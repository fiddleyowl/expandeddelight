# Expanded Delight — NeoForge 26.1.2

A Minecraft 26.1.2 / NeoForge port of Expanded Delight, a Farmer's Delight addon with new crops, cinnamon wood, food, cheese fermentation, and a juicer.

## Authors and credits

- **ianm1647** — original Expanded Delight code and assets. [GitHub](https://github.com/ianm1647/expandeddelight) · [CurseForge](https://www.curseforge.com/minecraft/mc-mods/expanded-delight).
- **vectorwing** — Farmer's Delight; **BuaichiZY** — its [26.1.2 port](https://github.com/BuaichiZY/FarmersDelight_26_Neo.ver/tree/26.1.2), whose recipe, recipe book, screen, and tooltip code this port adapts.

## Requirements

- Minecraft **26.1.2** with NeoForge **26.1.2.126+** within the 26.1.2 series.
- Java **25**.
- [Farmer's Delight 26 Neo Ver **1.3.3-fix8**](https://www.curseforge.com/minecraft/mc-mods/farmers-delight-26-neo-ver/files/9236195), installed separately.

## Port changes

Updated Minecraft/NeoForge APIs and data formats, juicer processing and persistence, the recipe book and client synchronization, cinnamon boats, food effects, trades, world generation, and JEI/KubeJS integration. Original content IDs, assets, translations, and recipe content are retained.

See [DEVELOPMENT.md](DEVELOPMENT.md) for the source baseline, build instructions, compatibility checks, and testing.
